# Every kind of github.com link, and what it must do in ghtui.
#
# Each line: a real example URL, then what it opens:
#   <Route>             a ghtui page (the `Route` variant's name)
#   files               the diff viewer
#   external <reason>   the browser, for one of these reasons:
#     download    a file to save (archives, release assets, raw files, .patch)
#     session     needs a browser session, writes, or needs rights the token
#                 doesn't give (settings, login, new issue, security alerts)
#     scope       needs a token scope gh doesn't grant by default
#                 (read:project, read:packages)
#     not-github  not repository or user content (GitHub's marketing, docs
#                 and other sites)
#     no-api      the API doesn't expose it
#     rare        rare and costly to build for what it shows
#
# Sources, in the order the PR describes: (a) GraphQL types with a URL,
# from scripts/url-inventory.sh; (b) `html_url` shapes in GitHub's REST API
# description; (c) website views, from GitHub's docs and
# scripts/page-links.sh; (d) shapes the live crawl (link_crawl) found.
